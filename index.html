Performia

Le problèmeThe problem

La machine doit mesurer la force de l’athlète et ajuster la résistance en temps réel, pendant que plusieurs sous-systèmes échangent des données sans en perdre.The machine has to measure the athlete’s force and adjust resistance in real time, while several subsystems exchange data without losing any.

ArchitectureArchitecture

  1. Capteurs de forceForce sensorsHX711
  2. ESP32FreeRTOS, 5 tâches sur 2 cœursFreeRTOS, 5 tasks on 2 cores
  3. Lien de donnéesData linkManchester, CRC16, ARQ
  4. Écran tactileTouchscreenNextion, UART

DécisionsDecisions

  • Déporter le rendu graphique sur l’écran Nextion pour ne pas surcharger l’ESP32, qui gère déjà les capteurs et la boucle de contrôle.Offload graphics rendering to the Nextion screen so the ESP32, already running the sensors and control loop, is not overloaded.
  • Protocole en cinq phases : initialisation, flux continu, détection de fautes, retransmission et fermeture.Five-phase protocol: initialization, continuous flow, fault detection, retransmission and closure.
  • Code de remplacement basé sur RMT pour les tâches PHY_TX et PHY_RX.RMT-based replacement code for the PHY_TX and PHY_RX tasks.

Défis résolusChallenges solved

  • Plantage du watchdog : le Core 0 était affamé par le bit-banging.Watchdog crash: bit-banging was starving Core 0.
  • Désalignement de phase dans PHY_RX, causé par la latence des interruptions.Phase misalignment in PHY_RX caused by interrupt latency.
  • Préambule erroné : huit bits à zéro au lieu du motif alterné 0x55.Wrong preamble: eight zero bits instead of the alternating 0x55 pattern.

Où ça en estWhere it stands

Débit utile calculé d’environ 18 kbit/s. Le projet est toujours en cours.Calculated useful throughput of about 18 kbit/s. The project is still in progress.

Industrial RAG Assistant

Le problèmeThe problem

Dans une usine, la réponse existe souvent déjà, mais elle est perdue dans des manuels, des procédures de maintenance et des fiches techniques. L’assistant doit répondre en montrant ses sources.In a factory, the answer often already exists, but it is buried in manuals, maintenance procedures and datasheets. The assistant has to answer and show its sources.

ArchitectureArchitecture

  1. DocumentsManuels, procédures, fichesManuals, procedures, datasheets
  2. IngestionIngestionFastAPI
  3. Recherche hybrideHybrid searchPostgreSQL, pgvector
  4. Réponse citéeCited answerGemini, Next.js

DécisionsDecisions

  • Définir d’abord les frontières des services, le modèle de données et les contrats d’API v1 : ingest, ask et health.Define service boundaries, the data model and the v1 API contracts first: ingest, ask and health.
  • Faire tourner tous les services avec Docker Compose.Run all services through Docker Compose.
  • Rendre chaque réponse vérifiable : l’API contrôle les citations et écarte une réponse sans source valide.Make every answer verifiable: the API checks the citations and discards an answer with no valid source.
  • Combiner recherche vectorielle, texte français et codes exacts, parce que les embeddings gèrent mal une référence comme T88-PROBE-02.Combine vector search, French full-text and exact codes, because embeddings handle a reference like T88-PROBE-02 poorly.
  • Refuser de répondre sous un seuil de pertinence plutôt que d’inventer.Decline to answer below a relevance threshold rather than make something up.

Où ça en estWhere it stands

Le pipeline complet fonctionne : ingestion PDF, recherche hybride, réponses citées et évaluation automatisée dans l’intégration continue. Sur un petit corpus de 3 documents, le bon passage arrive en premier pour 12 questions sur 12.The full pipeline works: PDF ingestion, hybrid search, cited answers and automated evaluation in CI. On a small corpus of 3 documents, the right passage ranks first for 12 questions out of 12.
